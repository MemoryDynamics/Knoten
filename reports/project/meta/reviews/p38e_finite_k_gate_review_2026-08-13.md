## Referee verdict

The result is useful but negative/inconclusive: the tested canonical scalar
response does not select an emergent `(m,p)` closure. All intervention-validity
controls pass, yet no registered wavenumber passes the complete temporal gate.
P3.8d must remain a constructed extension.

This is not a no-go theorem for every projection of `z=(x,rho)`. In
particular, the registered chronological holdout begins after the measured
response has nearly vanished, and the intervention initializes a valid
finite-`k` memory-state perturbation rather than writing it through the
canonical trajectory-deposition port. The defensible conclusion is therefore
"null not rejected", not "scalar memory can never yield a second state".

At `kR=0.5`, second order improves over first order but does not improve over
the delay null and has two real roots. At `kR=1`, AR(8) is better. The other
three channels prefer first order or the delay model. Truncation at 800
updates changes individual rankings but still yields at most one competitive
underdamped channel.

## Code review

- The branch construction preserves the youngest point and weighted centroid
  and normalizes each profile by weighted RMS.
- Paired signs and `eta=0` use the same future-noise array; the central
  derivative is divided by the physical perturbation amplitude.
- Centered Fourier readouts are translation invariant; a separate unit test
  verifies rigid translation equivariance.
- Recursive holdout prediction uses model-generated past values after the
  split. The reported score is not teacher forcing.
- The damped AR(2) parameterization is the exact sampled recurrence of
  `y''+2 gamma y'+omega_0^2 y=0`. It is only a necessary temporal condition;
  the implementation does not label it a completed passivity test.
- `589` repository tests pass and Ruff reports no issue in active code or
  tests. No result-changing implementation defect was found.

## Scientific decision

1. Do not tune `delta`, kernel amplitudes, damping or P3.8d coefficients to
   make these responses oscillatory.
2. Do not run a longer P3.8d simulation; its imposed state order cannot select
   itself.
3. If the scalar branch receives one final falsification test, use a
   zero-net, paired visible trajectory pulse that writes through the canonical
   deposition channel, then measure an independent finite-`k` memory/force
   readout. Fix its signal-support window from the known 600-update horizon,
   not from observed fit quality.
4. If that canonical write-port test also fails, an oriented/current memory
   or a registered shared multi-source field must be introduced openly as a
   model extension. Only then can balanced controllability/observability,
   storage metrics and reciprocal power ports justify naming a reduced state
   `p`.

## Claim boundary

Evidence: controlled finite-`k` susceptibility of mature scalar-memory states
and failure of a preregistered second-order closure gate.

Inference: the present scalar model supplies a strongly damped, heterogeneous
transient response but no selected reversible two-state mode in this
projection.

Not established: a universal scalar-memory no-go theorem, emergent momentum,
cross-node mediation, passivity, spin, quantization, particle identity,
physical mass or dimension selection.
